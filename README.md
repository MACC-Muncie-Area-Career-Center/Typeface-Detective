# Typeface Detective

Interactive typography identification game for Digital Design students.

## Learn Mode
- Level 1: Category Detective
- Level 2: Typeface Match
- Level 3: Expert

## Test Mode
Students choose 10, 20, 30, 40, or 50 questions and identify the typeface category.

## GitHub Pages
The game entry point is `index.html`.

After enabling GitHub Pages for this repository, GitHub will publish the game as a live webpage.

## Internet Requirement
The game uses Google Fonts for its typeface library, so students need internet access while playing.
